# NEXORA-AI-PRESENTATION
Professional presentation of NEXORA AI, an AI-powered Telegram assistant built with Python and Google Gemini.
NEXORA AI 🤖

AI-Powered Telegram Assistant

NEXORA AI is a Python-based Telegram chatbot powered by Google's Gemini AI.

It provides an intelligent conversational experience with persistent conversation history, Arabic-friendly responses, and daily usage management.

✨ Features

- AI-powered conversations using Google Gemini
- Arabic and multilingual interaction
- Persistent conversation history with SQLite
- Start fresh conversations using "/new"
- Daily usage limits for Free and PRO tiers
- Long-message handling
- Telegram bot integration

🛠 Technology Stack

- Python
- Telegram Bot API
- Google Gemini API
- SQLite
- python-telegram-bot
- Google GenAI SDK

⚙️ Requirements

The buyer must provide:

- Their own Telegram Bot Token
- Their own Google Gemini API Key
- A Python environment and hosting service

📌 Current Project Status

- Core chatbot functionality implemented
- SQLite conversation storage implemented
- Daily usage limits implemented
- Telegram Stars payment processing is not implemented
- PRO payment activation is not automated
